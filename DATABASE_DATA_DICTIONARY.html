🏗️ 数据架构层级

数据源层 (基础主表)

这些表是系统的基础数据源，不依赖其他表

🏭 equipment
生产设备 - 设备 ID、型号、部门分配等
🏪 stations
生产站点 - 工作站、部门、配置参数
📦 products
产品主表 - 产品 ID、名称、规格等
🔀 process_routes
工艺路线 - 生产流程定义
⚙️ parameters
参数定义 - 工艺参数、测量参数等
🗂️ parameter_groups
参数分组 - 参数的分类管理

中间层 (业务执行)

这些表记录生产过程中的实际执行数据且包含历史记录

📋 batches
生产批次 - 批次号、订单关联、状态等
📍 sub_batches
子批次 - 批次的细分单位
📊 production_events
生产事件 - 站点、设备、参数事件记录
✅ quality_records
质量记录 - 测量数据、检验结果
📈 oee_records
OEE 记录 - 设备综合效率数据
🧪 wafer_inspection_results
晶圆检测 - 晶圆检验数据

应用层 (功能性表)

支持特定应用功能的表

💬 chat_messages
聊天消息 - NL2SQL 对话系统的消息
💭 chat_sessions
聊天会话 - 对话会话管理
📝 schema_table_annotations
表注释 - 数据库表的说明文档
📌 schema_column_annotations
列注释 - 数据库列的说明文档
💬 feedback
用户反馈 - 系统反馈与建议

📚 学习路径建议

初级 - 理解基础表

  1. batches - 了解生产批次的基本概念
  2. products - 理解产品定义
  3. stations - 认识生产站点
  4. quality_records - 掌握质量数据

中级 - 掌握表关系

  1. sub_batches - 理解批次层级
  2. production_events - 了解生产过程
  3. wafer_inspection_results - 理解检测数据
  4. parameters - 掌握参数定义

高级 - 复杂查询

  1. 多表联接查询
  2. 时间序列数据分析
  3. 设备 OEE 计算
  4. 质量趋势分析

⚠️ 注意事项

⚙️ 时间戳约定:
  • created_at - 记录创建时间（不可修改）
  • updated_at - 记录最后更新时间（自动更新）
  • 所有时间戳为 UTC 时区
🔑 外键关系:
  • 删除主表记录要检查从表是否有关联数据
  • 某些表有级联删除规则，某些有保护规则
  • 生产历史数据通常被保护不可删除
ℹ️ 数据完整性:
  • 某些列有唯一性约束（UNIQUE）
  • 某些列有非空约束（NOT NULL）
  • 数值列有默认值或范围限制

🔍 NL2SQL 查询示例

Q: "显示最近 7 天的质量记录"

📊 系统会自动识别：

  • 表: quality_records
  • 时间范围: CURRENT_DATE - 7 days
  • 排序: created_at DESC

Q: "各个站点今日生产了多少产品"

📊 系统会自动识别：

  • 表: production_events (或 wafer_inspection_results)
  • 分组: stations
  • 聚合: COUNT(*)
  • 时间: TODAY()
