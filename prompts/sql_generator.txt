# ── 1a. 错误类型与修正指导规则 ──
# "not found" / "does not exist" → 表名或列名不存在。请参照下方 Schema 使用正确的名称。
# "validation"                   → SQL 预验证失败。请参照 Schema 修正表名/列名。
# "syntax"                       → SQL 语法错误。请检查语法是否正确。
# "permission" / "denied"        → 权限不足。请确保只使用 SELECT 查询。
# "timeout"                      → 查询超时。请简化查询，添加 LIMIT 或减少数据量。
# 其他                           → 请分析错误原因并修正 SQL。
# 最后一次重试 (retry >= 2)      → 追加: 这是最后一次重试机会！请使用最保守的查询方式，确保表名和列名完全匹配 Schema。
